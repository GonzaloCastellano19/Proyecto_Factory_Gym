# SportFactory Gym · prototipo web

Requisitos: Node.js 14 o superior. No hay que instalar nada (`npm install` no es necesario).

```bash
cd sportfactory-web
npm start
```

Abre http://localhost:3000 (versión creativa) o http://localhost:3000/clasica (versión clásica).
Para usar otro puerto: `PORT=8080 npm start` (en Windows PowerShell: `$env:PORT=8080; npm start`).

Las fuentes se cargan desde Google Fonts, así que hace falta conexión a internet para verlas.
Los horarios, plazas y avisos son datos de ejemplo.
