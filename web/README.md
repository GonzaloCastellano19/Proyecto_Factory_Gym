# web

Panel web y página pública (React + TypeScript + Vite).

Aún sin empezar la versión final. Mientras tanto, la carpeta [`prototipo/`](prototipo/) contiene un **prototipo navegable** de la web pública del gimnasio, hecho en HTML, CSS y JavaScript, con dos versiones: una creativa y una clásica.

Para verlo en local (necesita Node.js 14 o superior):

```bash
cd web/prototipo
npm start
```

Después abre http://localhost:3000 (creativa) o http://localhost:3000/clasica (clásica).
